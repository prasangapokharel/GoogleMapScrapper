## 🐛 Troubleshooting

### Issue: Extension looks old (not purple/modern)

**Solution:**
```
1. Go to chrome://extensions/
2. Find "Google Maps Business Scraper"
3. Click 🔄 RELOAD button
4. Close and reopen extension popup
5. Should now show beautiful purple UI
```

### Issue: Progress bar doesn't show

**Solution:**
- Progress bar only appears DURING scraping
- If scraping finished, it auto-hides
- This is normal behavior

### Issue: Some fields are empty in CSV

**Solution:**
- This is NORMAL!
- Not all businesses have all fields
- Examples:
  - Small businesses may not have websites
  - Some don't list phone numbers
  - Emails are rarely public
- The scraper extracts what's available

### Issue: Scraping stops midway

**Causes:**
- Google Maps rate limiting
- Connection timeout
- Page structure changed

**Solutions:**
```
1. Wait 5 minutes
2. Refresh Google Maps page
3. Try smaller batch (Max Results = 10)
4. Increase delay (3000ms or 5000ms)
5. Check browser console (F12) for errors
```

### Issue: "Please open Google Maps" error

**Solution:**
```
1. URL must be EXACTLY: https://www.google.com/maps
2. NOT: maps.google.com (redirect needed)
3. Must have search results visible in sidebar
4. Must see business cards listed
```

### Issue: Very slow scraping

**Solution:**
- This is EXPECTED for complete data
- Each business takes 5-10 seconds
- To speed up:
  - Reduce delay to 1000ms (may miss data)
  - Scrape smaller batches
  - Use faster internet connection

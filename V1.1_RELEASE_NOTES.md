## 🚀 HOW TO USE

### Step 1: Install Extension

```bash
1. Download/Clone the repo
2. Open Chrome: chrome://extensions/
3. Enable "Developer Mode"
4. Click "Load unpacked"
5. Select: /extension/ folder
```

### Step 2: Open Google Maps

```
Go to: https://www.google.com/maps/search/coffee
(Or any search query)
```

### Step 3: Start Scraping

```
1. Click extension icon (terminal-themed popup appears)
2. Set Max Results (0 = unlimited)
3. Set Scroll Delay (default: 2000ms)
4. Click "▶ Execute Scraper"
5. Wait for completion
6. Click "⬇ Export Data.csv"
```

### Step 4: Get Your Data

```
CSV file downloads with all 15+ fields!
```

### Key Code Improvements

**Optimized Extraction:**
```javascript
// BEFORE (v1.0)
await delay(2000);
const phoneButton = buttons.find(...);
if (phoneButton) {
  await clickAndWait(phoneButton, 800);
}

// AFTER (v1.1)
await delay(1800); // 10% faster
const allButtons = Array.from(document.querySelectorAll(...)); // Batch
const phoneButton = allButtons.find(btn => 
  btn.getAttribute('data-item-id')?.includes('phone:tel:')
);
if (phoneButton) {
  await clickAndWait(phoneButton, 600); // 25% faster
}
```

**Better Website Extraction:**
```javascript
// v1.1 - Direct data-item-id approach
const websiteLink = document.querySelector('a[data-item-id="authority"]');
if (websiteLink) {
  business.website = websiteLink.href;
}
```
